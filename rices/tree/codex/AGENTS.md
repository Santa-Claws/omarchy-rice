# Personal completion preferences

- Before every final response, decide whether the requested task was completed successfully. In the final response's last `Summary` section, include exactly one of these sentences: `Task result: Success.` or `Task result: Failure.` Use failure when a required part remains blocked, unverified, or incomplete.
- If you created a Git commit during the task, add one short sentence as the final line of the `Summary` section saying that it was committed, naming the repository and short commit hash, and whether it was pushed. Do not claim a push unless it succeeded.
- Keep the `Summary` section brief.
